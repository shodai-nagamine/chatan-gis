# chatan-gis — 北谷町 統計マップ

沖縄県北谷町の統計を、**町丁字（字・丁目）単位**の地図で見るための静的サイト。
人口・年齢構成・世帯の指標を塗り分け、医療機関と介護事業所を点で重ね、
議会会議録での言及を字に紐づける。

公開先: GitHub Pages（`docs/` をそのまま配信）

## できること

| | |
|---|---|
| 町丁字マップ | 北谷町を **29区域**に分け、11指標で塗り分け。ホバーで値、クリックで詳細 |
| 指標 | 人口 / 人口密度 / 人口増減率(2015→2020) / 高齢化率 / 75歳以上 / 高齢化の進み方 / 年少人口率 / 高齢者のいる世帯 / 子どものいる世帯 / 単身世帯率 / 平均世帯人員 |
| 施設 | 医療機関34・介護事業所32（入所7・通所14・訪問相談11）を点表示。カテゴリで切替 |
| 議会 | 沖縄県議会で北谷町に触れた発言7件。字が特定できたものは区域の詳細にも出る |

## データ元

| 種類 | 出典 | 備考 |
|---|---|---|
| 境界 | e-Stat 統計GIS「令和2年国勢調査 町丁・字等別境界データ」 | 世界測地系 JGD2000 |
| 人口・世帯 | 総務省統計局 令和2年国勢調査 小地域集計（`T0001081`〜`T0001084`） | 比較用に平成27年（`T000848`〜`T000851`） |
| 医療機関 | 国土交通省「国土数値情報（医療機関データ P04）」2020年 | 緯度経度つき |
| 介護事業所 | 厚生労働省「介護サービス情報公表システム」オープンデータ | CC BY 相当。緯度経度つき |
| 議会会議録 | 沖縄県議会 会議録検索システム | 抜粋と原文リンクのみ。本文は載せない |

## 作り直し方

```bash
uv sync
uv run python scripts/build_areas.py       # 境界＋国勢調査 → docs/data/chatan_areas.geojson
uv run python scripts/build_facilities.py  # 医療＋介護 → docs/data/chatan_facilities.geojson
uv run python scripts/build_speeches.py    # 議会言及 → docs/data/chatan_speeches.json
```

取得したファイルは `data/raw/`（gitignore済み）にキャッシュされるので、2回目以降は速い。

`build_speeches.py` だけは [okinawa-civic-api](https://github.com/shodai-nagamine/okinawa-civic-api)
の PostgreSQL（`okinawa_civic`）が手元にあることが前提。無い場合は既存の
`docs/data/chatan_speeches.json` がそのまま使われる。

## データを扱う上で気をつけたこと

**境界と統計の対応**
e-Statの境界データは、道路や基地で分断された区域を別レコードに分けて持っている
（字吉原0050-02 は2レコードで、人口は片方にだけ入る）。区域コードで束ねないと
二重計上になるため、`build_areas.py` で統合したうえで
**区域の人口合計が町計（28,201人）と一致すること**をビルド時に検証している。

**同名の字**
字吉原は6区画、字桑江は5区画ある。表示名は基本単位区コードを添えて
「字吉原〔0050-03〕」のように区別している。

**外れ値**
字伊平は2015→2020で172人→821人（+377%）と跳ねている（返還跡地の宅地化）。
増減系の階級区分は最大値で割ると全体が潰れるため、絶対値の分位で境界を決めている。

**人口の少ない区域**
字桑江〔0070-02〕は19人しかいない。数人の増減で比率が大きく動くので、
詳細パネルに注意書きを出している。

**同名地名の誤検出**
議会会議録の地名抽出では、伊平屋村・伊是名村（→字伊平）、宮城島・宮城県・宮城力局長
（→字宮城）、空港や港湾（→字港）を除外している。「北谷」が近くにあることも条件。

**福祉・医療の統計は市町村単位まで**
要介護認定率や医療費といった指標は字別には存在しない。このサイトが字別に出しているのは
国勢調査から算出できる範囲（高齢化率・高齢者のいる世帯の割合など）に限っている。

## 未収録

  `Disallow: /` ＋ `Allow: /tenant/` で、本文を返すAPI `/dnp/search/` は Disallow 側にある。
  `/tenant/` 配下の公開ページはJavaScriptの器だけで本文を持たない。
  議会事務局の許諾が取れ次第、`build_speeches.py` に足す。
